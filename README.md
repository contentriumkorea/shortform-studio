## 설치와 업데이트

1. 최신 릴리스에서 `ContentriumShortformStudio-Setup.exe`를 받습니다.
2. 설치 프로그램을 실행합니다. 최초 설치에는 필수 영상 엔진을 내려받기 위한 인터넷 연결이 필요합니다.
3. 전체 기능은 관리자에게 별도로 받은 활성화 정보로 사용합니다. 활성화 정보는 공개 이슈에 올리지 마세요.
4. 설치된 프로그램은 **설정 → 업데이트 → 업데이트 확인 → 검증된 설치파일 받기 → 저장 후 설치** 순서로 업데이트합니다. 작업 중이거나 저장에 실패한 경우 먼저 해당 상태를 해결합니다.

Windows 10/11 x64 대상입니다. Windows 게시자 서명 인증서는 적용되지 않아 알 수 없는 게시자 경고가 나타날 수 있습니다. 업데이트 서명·파일 해시 검증과 Windows 게시자 서명은 별개입니다. 보안 프로그램이 악성코드로 차단하면 예외 처리로 우회하지 말고 진단 정보를 관리자에게 전달해 주세요.

0.6.0~0.6.2에서 “설치 도우미 준비를 확인하지 못했습니다”가 나오면 작업을 저장하고 앱을 완전히 종료한 뒤 최신 설치파일을 직접 실행하세요. 사전 제거는 필요하지 않습니다. 0.3.0 사용자도 최신 설치파일을 직접 받으세요.

## 수집과 기본 편집

0.9.2부터 경상북도 게시판의 일부 영상 주소 확인 실패는 별도 재확인 대상으로 보관합니다. 정상 목록 수집은 계속되며, 전체 확인 완료 후에는 새 자료를 확인합니다. 과거 전체 페이지를 다시 확인하려면 `전체 다시 가져오기`를 사용하세요. `등록 목록`은 원본 영상 다운로드 수가 아닙니다.

편집은 미리보기와 제목·자막·문장 선택을 함께 보는 쉬운 화면으로 시작합니다. 필요하면 상세 화면으로 전환해 타임라인, 자르기, 위치·음량 등을 조절합니다. 두 화면은 같은 편집본을 사용하며 편집 중에도 작은 영상 추가 버튼으로 가져오기 창을 열 수 있습니다.

추천 방식은 자동·대화 중심·행사/장면 중심으로 고릅니다. 한 후보만 바꾸거나 유지할 후보와 사용하지 않을 구간을 지정할 수 있고, 새 결과는 비교 후 적용합니다. 적합한 발화 후보가 없으면 저장된 장면 경계의 검토용 초안을 만들거나 직접 구간을 선택합니다. 장면 초안은 영상의 내용을 이해한 결과가 아니며 제목·자막·구간을 직접 확인해야 합니다. 선택만으로 AI 작업이 시작되지는 않습니다.

내 영상 파일, YouTube 링크, 지원 게시판·채널을 사용할 수 있습니다. 기본 등록 출처는 없으며, 팔로우 등록 시 지원 목록의 과거 자료부터 확인합니다. 원본은 선택해서 내려받고 자동 후보 생성을 켜면 다운로드·분석도 진행합니다. 마지막 확인·실제 자료 추가·전체 확인 성공 시각과 중단 위치를 구분합니다. 로그인·동적 더보기·전용 플레이어 등은 별도 지원이 필요하며 모든 웹사이트의 전체 파일 수집을 보장하지 않습니다. 접근·다운로드 권한이 있는 자료만 사용하세요.

상단 제목과 음성 자막을 독립적으로 편집하고, 영상 맞춤·확대·위치·상하 프레임·자막 시간과 문구를 조절합니다. 선택 구간의 음성을 다시 인식해 확인 후 적용할 수 있습니다. 자동 자막은 고유명사·소음 등에서 오류가 생길 수 있으므로 게시 전 전체 재생 검토가 필요합니다. 플랫폼 안전 영역은 가이드이며 실제 게시 화면은 기기와 앱 UI에 따라 달라질 수 있습니다.

## AI 모드와 실행 확인

- 다운로드·음성 인식·자막·영상 출력은 로컬 자원으로 처리합니다.
- 로컬 모드는 준비된 로컬 엔진을 사용하며, 규칙 기반 초안과 로컬 LLM 결과를 구분합니다.
- Chat GPT 모드는 별도 로그인·전송 동의가 필요합니다. 중앙의 자동 분업 또는 직접 설정으로 GPT-6 모델과 추론 강도를 선택하며, 실패 시 로컬 결과로 몰래 바꾸지 않습니다. 직접 선택에서는 선택한 모델을 유지합니다.
- 작업의 **실행 기록**에서 요청 모델, 응답 수신, 검증·적용 여부와 제공된 사용량을 확인합니다. 응답이 보고하지 않은 모델 정보는 추정하지 않습니다.
- **Chat GPT 계정으로 연결**은 앱 전용 로그인 연결입니다. 다른 앱의 열린 대화를 조작하지 않습니다. 계정에서 제공하는 사용량과 갱신 시각을 표시하며, 조회하지 못한 값은 0으로 표시하지 않습니다.
- 긴 전사는 나누어 분석합니다. 실패 후 다시 시도할 때 입력·설정이 같은 성공 단계는 재사용하고 새 호출과 구분합니다. 분석에서 빠진 발화는 검토 안내로 표시합니다.
- 대표 화면 전송은 별도 동의 시 최대 6장만 사용합니다. 상세 요청·응답 보관도 별도 선택이며, 일반 진단 내보내기에는 포함하지 않습니다.

제목과 자막은 자동 생성 뒤 검토해 주세요. 제목 단독 로컬 추천은 제한된 문구 규칙을 사용합니다. 의미 검사는 모든 사실관계를 보증하지 않으며, 지원 모델과 기능 제한은 해당 릴리스 안내를 확인하세요.
